# 🚀 Infinity Hub

Plataforma SaaS para gestão de pequenos negócios.

## 💡 Sobre o projeto

O Infinity Hub é um sistema desenvolvido para automatizar e organizar operações de negócios como:

- 📅 Agendamentos
- 💰 Controle financeiro
- 📦 Gestão de pedidos
- 👤 Cadastro de clientes

O objetivo é oferecer uma solução simples, moderna e acessível para empreendedores.

---

## 🧠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- (Futuro: Firebase / Supabase)

---

## 🎯 Funcionalidades (MVP)

- Sistema de login
- Dashboard interativo
- Navegação entre módulos
- Estrutura pronta para expansão

---

## 🚀 Futuras melhorias

- 🔐 Autenticação real (Firebase)
- 💾 Banco de dados
- 📱 PWA (App instalável)
- 📊 Dashboard com métricas reais
- 💳 Integração com pagamentos
